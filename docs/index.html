Sobre este despliegue

Esta es una version estatica desplegada en GitHub Pages. Los datos se guardan en el almacenamiento local del navegador (localStorage) y se pierden al limpiar los datos del sitio.

Para la version completa con backend Flask + SQLite, descarga el repositorio y ejecuta:

git clone https://github.com/Styveensoon/TaskManager-DevOps.git
cd TaskManager-DevOps
pip install -r requirements.txt
python app.py
